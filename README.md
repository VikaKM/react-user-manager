# React User Manager

Тестовое задание на позицию Frontend Developer.

## Описание

Двухстраничное приложение на React для отображения и редактирования пользователей.

### Главная страница
На главной странице отображается список пользователей, полученных с API:

`https://jsonplaceholder.typicode.com/users`

В интерфейсе реализовано:
- вывод первых 6 пользователей
- карточки пользователей с основной информацией
- архивирование карточек
- скрытие карточек
- восстановление карточек из архива (активация)
- loader во время загрузки данных

Каждая карточка содержит:
- Username
- City
- Company name
- Avatar

Реализовано управление состоянием карточек:
- активные
- архивные (с возможностью восстановления)
- скрытые

> Данные состояния карточек могут сбрасываться после перезагрузки страницы.

### Страница редактирования
На странице редактирования отображаются и редактируются поля:
- Name
- Username
- Email
- City
- Phone
- Company Name
- Avatar

Реализована валидация формы:
- **Name** — от 2 до 64 символов
- **Username** — от 2 до 64 символов
- **Email** — базовая валидация через Zod
- **City** — от 2 до 64 символов
- **Phone** — только цифры
- **Company Name** — от 2 до 64 символов

После успешного сохранения формы показывается popup с сообщением:
- закрытие по крестику
- закрытие по клику на подложку
- автоматическое закрытие через 4 секунды

> Изменения могут не сохраняться после перезагрузки страницы и возврата на главную.

## Функциональность

- получение данных пользователей с внешнего API
- отображение списка пользователей
- loader во время загрузки
- архивирование и возврат карточек
- скрытие карточек
- переход на страницу редактирования
- редактирование данных пользователя через форму
- валидация формы
- popup об успешном сохранении
- адаптивная верстка
